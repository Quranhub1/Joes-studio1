# Joes Studio

Joes Studio is a lightweight web-based visual paper design and printing tool.

## Main capabilities

- Create and edit paper layouts visually
- Start from editable templates
- Add text, images, tables, shapes and barcodes
- Import Excel data for variable fields and batch output
- Save and open `.paper` project files
- Export designs to PDF
- Print directly from the browser
- Work locally in the browser without requiring a server

The application interface is provided in English and the product is branded as **Joes Studio**.
